# kmap 美术素材 · 提示词包

给做图的 agent 用。**请先读完第 0 节再动手** —— 那一节里的约束决定了素材能不能贴上，
不是风格偏好。

---

## 0. 整合约束（决定素材能不能用）

| 约束 | 为什么 |
|---|---|
| **PNG-32，背景透明** | App 支持深色模式，背景会在 `#FDF7EC`（奶油白）和 `#1A1614`（近黑）之间切换。带底色的图在深色模式下会是一块突兀的白板。 |
| **图里绝对不能有文字、字母、数字、水印、签名** | 所有文字都由代码画（要能改、要清晰、要随语言变）。图上带字 = 那张图废掉。 |
| **深色粗描边**（约 3–5px @1024） | 一是本项目的视觉语言（厚描边 + 平涂），二是图会坐在浅色和深色两种背景上，没有描边在浅色背景上会糊成一片。 |
| **不要用纯白 `#FFFFFF`、不要纯黑 `#000000`** | 纯白在深色背景上会发光刺眼。描边用深褐 `#2B2118`，高光用 `#FFF8EC`。 |
| **地形图：正方形，四边出血** | 地形图会被裁成**不规则岛屿形状**（不是圆形、不是方框），所以边缘请画满、内容可以延伸出画面。 |
| **地形图：中心约 60% 要相对干净** | 那里会盖一座城堡 + 两行年级文字。中心画了主景的话，贴上去全被挡掉。 |
| **城堡：底部要有一点点落地阴影** | 不然看起来是飘在岛上的。阴影要小、要柔和。 |
| **城堡：旗子请留白** | 旗子由代码画 —— **旗的颜色代表战况**（已消灭=金、有异动=红）。画上去就失去这个信息了。 |

裁剪轮廓的**真实形状**见 `art/isles-mask.svg`（虚线框 = 中心留白区）。

## 1. 风格前言（**每一段提示词前面都要粘这一整段**）

```
儿童向扁平卡通插画。厚描边手绘感：主轮廓用深褐色 #2B2118 的粗线（约 4px@1024），
线宽均匀、圆头收尾。主体用平涂色块，允许极轻的柔和明暗（不要写实光影、
不要复杂渐变、不要塑料 3D 渲染感）。统一光源来自左上。造型圆润、大圆角、
线条干净闭合。配色温暖明快、饱和度高但不刺眼，参考色板：
奶油白 #FDF7EC、草绿 #5FB84A、天蓝 #3FA9D6、暖橙 #E8A33D、
青绿 #3FA37F、紫 #8B77D4、珊瑚红 #E2604A。

这是给 11~12 岁孩子用的学习游戏，气质是"冒险、轻快、干净"，
不是硬核战争：可以有旗帜、盾牌、城墙，但不要武器特写、不要士兵、
不要废墟残骸、不要任何血腥或阴暗的元素。

画面里不要出现任何文字、字母、数字、水印、签名。
输出 PNG，背景透明。
```

## 5. P1 · 三位领主（拟人角色设计）

**这是全套素材里最值得认真做的一组。** 领主是孩子在产品里最常看到的"人"——
他们会代表三门课，孩子会对他们有感情。所以不是画三个图标，是**设计三个角色**。

### ★ 唯一的硬指标：黑白剪影也要能一眼分开

三个领主会以**很小**的尺寸出现（卡片上现在只有 58×58 CSS px）。
所以**靠颜色区分是不够的** —— 颜色一缩小、一模糊就没了。
**必须靠剪影区分**：头型、发型、体型、道具轮廓，三者的外形要明显不同。

> **自检方法**：把三张图都填成纯黑、只留轮廓。
> 如果那时候还能一眼说出"这个是谁"，这组设计就成立了；
> 如果三个都是"圆头 + 圆身子"，那就不成立 —— 那是三个色块，不是三个角色。

### 三人同框（推荐先出这一张）

```
[风格前言] + [负向]
一张角色设定图：三个并排的卡通角色，**胸像到腰**，正面略偏，
同一套画风、同样的描边粗细、同样的光照、同样的头身比。
构图：三个角色等间距并排，站在同一条水平线上，背景透明。

★ 三者的**年龄感、体型、发型、头部轮廓**必须有明显差别 ——
不是三个同样身材换配色，而是三个一看就不一样的人。
★ 不要在他们身上或道具上写任何文字、字母、数字（这是重点，请务必避免）。

（下面接三位领主的设定）
```

### 可选：表情差分（P2）

不然三次生成的画风会飘）：


## 6. P1 · 三个军团徽记（含水印用法）

**用途**：区分三个军团。现在点进任何一科的军团页，长得都一样 ——
看不出"我在谁的军团里"。徽记要给这件事一个一眼可辨的答案。

它会以**两种尺寸**出现，这个前提决定了画法：

| 用法 | 尺寸 | 要求 |
|---|---|---|
| 页头纹章（配一行"数学军团"） | 约 34px | 缩到很小还要认得出 |
| **页面水印**（铺在整页内容后面） | 约 400px，透明度约 6% | **只有轮廓还能认出来** |

### ★★ 一条最关键的要求：**只画纹章主体，不要画外框**

外框（圆形底衬/盾牌框/绶带）**由代码统一画**。理由是它一举解决两个问题：

1. **三个外框统一** → 看起来是一套的（同一个游戏里的三个军团）。
2. **三个主体形状不同** → 缩到 34px 也分得清（外框都一样的话就只剩颜色能区分，
   而颜色一缩小就没了）。

同理，**不要去画细节纹理**：水印只有 6% 的透明度，任何内部细节都会消失，
最后能被看见的只有**整体轮廓**。所以请按"剪影先成立"来设计。

> **自检**：把徽记填成纯黑，缩到 34px 看一眼 —— 三个还能分开吗？
> 还会的话就成立；如果三个都是一团差不多的块，那就不成立。

### 交付形式

每个军团给**一个文件**：**单色实心剪影，颜色深褐 `#2B2118`，透明背景**。
代码负责上色和水印的透明度（这样同一张图既能当彩色纹章、又能当水印，
不用维护两套）。

### 三个徽记

```
[风格前言] + [负向]
一个纹章图案的**主体**（只画主体）。构图居中、左右对称、正方形画布、
主体占画面约 80%，背景透明。**不要**画外框、不要圆形底衬、不要盾牌轮廓、
不要绶带、不要文字。造型要能用**单一深褐色 #2B2118 实心填满**表达，
没有内部细节也能看懂是什么。
```

- **语文军团 ·「书卷纹」**
  一支**毛笔**与一卷**半展开的书简**交叉成 X 形。书简的卷轴端画成明显的圆筒
  （这是它轮廓上最好认的部分），毛笔的笔杆细长、笔锋饱满。
  整体是**横向展开的宽形**轮廓。

- **数学军团 ·「营造纹」**
  一把**张开的圆规**与一把**三角尺**交叉成 X 形。圆规两腿张开、
  顶端有转轴（圆形节点），三角尺是一个明确的直角三角形。
  整体是**尖角分明的放射形**轮廓 —— 和另外两个的圆润感形成对比。

- **英语军团 ·「号角纹」**
  一支**传令号角**（弯月形喇叭，开口朝右上），斜穿一面**展开的信笺**
  （长方形纸卷，四角微微卷起）。
  整体是**弧形 + 直线**的组合，重心偏一侧 —— 三个里唯一不对称的轮廓。

### 可选：军团底纹（P2）

如果想让军团页不那么空，还可以再要一张**无缝拼接的底纹**：

```
[风格前言] + [负向]
一张**无缝平铺**（seamless tile）的装饰底纹：把上面这个纹章缩小、
按斜向 45° 等距重复排布，图案之间留出充足空白。
整体只用单一深褐色 #2B2118 单色绘制，背景透明。
平铺后不能出现可见的接缝或明显的重复节奏感。
```

> 注意：底纹是**可选**的。页面水印（一个放大的徽记 + 6% 透明度）
> 已经能起到"我在哪个军团"的作用，而且更省事。

## 11. 我这边会怎么接（给 agent 的上下文，也可不写进提示词）

- 地形图会被当成 `<image>` 塞进 SVG，用 `<clipPath>` 裁成岛屿轮廓
  （形状见 `art/isles-mask.svg`），所以**边缘一定要出血**。
- 城堡、领主立绘、图标都是独立的 `<image>`，直接按坐标摆放，所以**必须透明背景**。
- 深色模式下会给整组图加一层轻微的降亮/降饱和（代码做），
  所以**不要自己画深色版本** —— 一套图两种模式通用。
- 旗面的颜色由代码决定，代表战况，所以**旗面留白**。

## 12. 四条最容易踩的坑

1. **六张地形风格不统一。** → 一次画六格拼图，或者先出试稿定调。
2. **三个领主长得像同一个人换了配色。** 这是角色设计最常见的失败。
   → **把三张图填成纯黑剪影自检**，分辨不出来就重画（见第 5 节）。
   分三次单独生成几乎必然出这个问题，务必**一张图里出三个**。
3. **图里带了文字。** 生成模型特别爱往袍子、书册、旗子、木牌上加字 ——
   一律不要。负向提示词里已经写了，但**出图后还是要逐张检查**
   （尤其领主的卷轴和地图，很容易被写上几个字母）。
4. **背景不是真透明。** 有些工具"看起来透明"实际是白底。
   交付前请用修图软件**关掉背景层**确认能看见透明棋盘格。
