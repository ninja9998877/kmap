# kmap 美术素材 · 提示词包

给做图的 agent 用。**请先读完第 0 节再动手** —— 那一节里的约束决定了素材能不能贴上，
不是风格偏好。

---

## 0. 整合约束（决定素材能不能用）

| 约束 | 为什么 |
|---|---|
| **PNG-32，背景透明** | App 支持深色模式，背景会在 `#FDF7EC`（奶油白）和 `#1A1614`（近黑）之间切换。带底色的图在深色模式下会是一块突兀的白板。 |
| **图里绝对不能有文字、字母、数字、水印、签名** | 所有文字都由代码画（要能改、要清晰、要随语言变）。图上带字 = 那张图废掉。 |
| **深色粗描边**（约 3–5px @1024） | 一是本项目的视觉语言（厚描边 + 平涂），二是图会坐在浅色和深色两种背景上，没有描边在浅色背景上会糊成一片。 |
| **不要用纯白 `#FFFFFF`、不要纯黑 `#000000`** | 纯白在深色背景上会发光刺眼。描边用深褐 `#2B2118`，高光用 `#FFF8EC`。 |
| **地形图：正方形，四边出血** | 地形图会被裁成**不规则岛屿形状**（不是圆形、不是方框），所以边缘请画满、内容可以延伸出画面。 |
| **地形图：中心约 60% 要相对干净** | 那里会盖一座城堡 + 两行年级文字。中心画了主景的话，贴上去全被挡掉。 |
| **城堡：底部要有一点点落地阴影** | 不然看起来是飘在岛上的。阴影要小、要柔和。 |
| **城堡：旗子请留白** | 旗子由代码画 —— **旗的颜色代表战况**（已消灭=金、有异动=红）。画上去就失去这个信息了。 |

裁剪轮廓的**真实形状**见 `art/isles-mask.svg`（虚线框 = 中心留白区）。

## 1. 风格前言（**每一段提示词前面都要粘这一整段**）

```
儿童向扁平卡通插画。厚描边手绘感：主轮廓用深褐色 #2B2118 的粗线（约 4px@1024），
线宽均匀、圆头收尾。主体用平涂色块，允许极轻的柔和明暗（不要写实光影、
不要复杂渐变、不要塑料 3D 渲染感）。统一光源来自左上。造型圆润、大圆角、
线条干净闭合。配色温暖明快、饱和度高但不刺眼，参考色板：
奶油白 #FDF7EC、草绿 #5FB84A、天蓝 #3FA9D6、暖橙 #E8A33D、
青绿 #3FA37F、紫 #8B77D4、珊瑚红 #E2604A。

这是给 11~12 岁孩子用的学习游戏，气质是"冒险、轻快、干净"，
不是硬核战争：可以有旗帜、盾牌、城墙，但不要武器特写、不要士兵、
不要废墟残骸、不要任何血腥或阴暗的元素。

画面里不要出现任何文字、字母、数字、水印、签名。
输出 PNG，背景透明。
```

**负向提示词（每次都带上）**

```
写实照片感, 3D 渲染塑料感, 暗黑哥特, 血腥, 武器特写, 士兵, 尸骸, 废墟,
文字, 字母, 数字, 标题, 水印, 签名, logo, 边框, 画框, 网格线, 棋盘格,
纯白背景, 纯黑描边, 复杂渐变, 写实光影, 景深虚化, 低分辨率锯齿
```

## 3. P0 · 六个地形图

> **做法建议：一次让 agent 画一张 3×2 的六格拼图，再切图。**
> 分六次画，六块地形大概率会像六个不同的游戏 —— 风格一致性是这组素材最大的风险。
>
> **动手之前先出一张试稿**（任选一个地形 + 城堡），确认风格再批量。省得六张全废。

**共用约束（每段里都重复一遍）**

```
正方形构图，四边出血（这张图会被裁成不规则岛屿形状，边缘请画满、可以延伸出画面）。

（那里会盖一座城堡和两行文字，不要放主景）。特色景物请布置在四周。
```

```
[风格前言] + [负向]
```

现在用 emoji 凑的（⚪ ⚔️ 🛡️ 🏳️ 🚩）。画成图标会更统一。
**五个要同一张图里一起画**，保证是同一套。

```
[风格前言] + [负向]
一排五个状态图标，同一套视觉语言、同样大小、同样描边粗细，
并排放在一张正方形画布上（五个等分格），背景透明。
每个图标都是极简的圆角造型，缩到 16px 还要认得出：

1. 未遭遇 —— 一个空的圆形徽章（灰）
2. 遭遇中 —— 两把交叉的棍棒/交叉的旗（暖橙）
3. 压制中 —— 一面盾牌（天蓝）
4. 已消灭 —— 一面旗杆上挂着收起的旗 + 一个小小的对勾（绿）
5. 有异动 —— 一面被风吹歪、缺了一角的旗（珊瑚红）

不要武器细节、不要刀剑刃口、不要文字。
```

## 10. 我这边会怎么接（给 agent 的上下文，也可不写进提示词）

- 地形图会被当成 `<image>` 塞进 SVG，用 `<clipPath>` 裁成岛屿轮廓
  （形状见 `art/isles-mask.svg`），所以**边缘一定要出血**。
- 城堡、领主立绘、图标都是独立的 `<image>`，直接按坐标摆放，所以**必须透明背景**。
- 深色模式下会给整组图加一层轻微的降亮/降饱和（代码做），
  所以**不要自己画深色版本** —— 一套图两种模式通用。
- 旗面的颜色由代码决定，代表战况，所以**旗面留白**。

## 11. 三条最容易踩的坑

1. **六张地形风格不统一。** → 一次画六格拼图，或者先出试稿定调。
2. **图里带了文字。** 生成模型很爱往旗子/木牌上加字 —— 一律不要，
   我们有专门的"不要文字"负向提示词，但**出图后还是要逐张检查**。
3. **背景不是真透明。** 有些工具"看起来透明"实际是白底。
   交付前请用修图软件**关掉背景层**确认能看见透明棋盘格。
