# art —— 界面素材放这里

**这是 UI 素材（工具的一部分），所以放公开仓库这边**，不是 `kmap-data` 里的资料。
（分界线见仓库根目录 README：能造出资料的机器是工具，资料本身不是。）

## 现在有什么

- `isles-mask.svg` —— 首页六块地形的**真实裁剪轮廓**（给做美术的人看）。
  虚线框是"中心留白区"（城堡和年级文字会盖在那里）。
  这个文件是 `.selftest/kmap-dump-isles.mjs` 从**真实页面**里读出来生成的，
  不是另写一份算法算的 —— 两处实现迟早对不上，而且对不上时不会报错。

## 素材要求

见 `docs/art-prompts.md`：**PNG-32 透明底、不要文字、深色粗描边**。
其中最容易被忽略的两条：

- 地形图会被裁成不规则岛屿，所以**四边要出血**、**中心 60% 要留白**。
- 城堡的**旗面要留白** —— 旗子的颜色由代码按战况画。

## 图来了之后

放这个目录，命名见 `docs/art-prompts.md` 第 9 节。
代码会用 `<clipPath>` 把地形裁成岛屿形状、把城堡和立绘按坐标摆上去。
**深色模式不另做一套**：整组图会被统一降亮，所以只要一套图。
